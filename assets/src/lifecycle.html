The memory lifecycle

Four skills that cover an auto-memory's whole life — from a clean slate to a reversible retirement
/freshStart at zero
Memory quarantine: the session acts as if the project had no auto-memory, and every subagent inherits the same instruction.
↓
/recallPull the minimum back
Read-only: lists matching index entries (with STALE tags), then opens exactly one topic file you name. Never writes.
↓
/checkupReview what went stale
Sweeps past-due review-after stamps and status-like notes; you pick per file: refresh, mark historical, stamp, forget, or skip.
↓
/forgetRetire what is finished
Moves whole-match files to .trash/, cuts matching lines from the rest, and records everything in a manifest with a restore recipe.
Every destructive-looking step is reversible: no memory file is ever deleted, and every cut line is copied verbatim into .trash/TRASH.md before the cut.
